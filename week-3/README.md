# Week 3 — Sprint 02: Make DR. MEOWW Interactive

## Target Pertemuan 3
- Halaman web yang dinamis dan interaktif menggunakan JavaScript / TypeScript dan state DOM.
- Penerapan *event handling* pada antarmuka:
  - Toggle menu navigasi mobile & tab navigasi aktif.
  - Tab kategori layanan (*Paket Grooming* vs *Penitipan Kucing*) dan kalkulasi tarif otomatis berdasarkan ukuran berat kucing (`< 2 kg`, `> 2 kg`, `> 5 kg`).
  - Carousel interaktif perbandingan *Before & After* perawatan.
  - Accordion interaktif pada seksi FAQ.
  - Modal & form reservasi interaktif lengkap dengan validasi input, kalkulasi estimasi biaya otomatis, penyimpanan state lokal sementara, dan ringkasan bukti reservasi.
- Belum terhubung ke REST API / server backend (integrasi API dimulai pada Pertemuan 4).

## Cara Menjalankan
```bash
cd frontend
npm install
npm run dev
```
