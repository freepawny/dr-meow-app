# Grooming Dr. Meow — Backend Week 04–07

Paket ini sengaja dipisahkan menjadi **empat folder mingguan**. Setiap folder adalah deliverable sesuai bobot materi minggu tersebut, bukan satu implementasi final yang seluruh materinya dikerjakan sekaligus.

## Struktur

- `week-04-api/` — menyediakan API JSON sederhana sebagai kontrak yang dapat dikonsumsi frontend dan diuji melalui Bruno.
- `week-05-php-server-side/` — memperlihatkan pemrosesan request dan data di sisi server menggunakan PHP.
- `week-06-oop/` — memodelkan domain layanan menggunakan Entity dan OOP.
- `week-07-mvc/` — menyusun implementasi menjadi arsitektur MVC backend yang menjadi fondasi integrasi berikutnya.

## Cara menggunakan

Kerjakan folder secara berurutan. Setiap folder memiliki README sendiri, struktur, dan batas materi. Jangan mencampur file dari minggu berikutnya ke minggu sebelumnya ketika mengumpulkan tugas mingguan.

**Catatan peran tim:** paket ini hanya berisi pekerjaan backend. Frontend React dikerjakan di repository/folder tim frontend. Frontend mengonsumsi endpoint JSON yang disediakan backend.

## Lingkup dan batasan

Data layanan pada minggu 4–7 masih berupa data contoh/statis untuk memenuhi tahapan pembelajaran dan menguji arsitektur. Jangan menganggap harga, jadwal, kapasitas, payment gateway, atau aturan operasional yang belum disetujui sebagai ketentuan final bisnis. Integrasi MariaDB, autentikasi, payment provider, scheduling concurrency, dan deployment produksi merupakan pekerjaan lanjutan.
