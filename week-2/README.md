# Week 2 — Sprint 01: Build the DR. MEOWW Web Interface

## Target Pertemuan 2
- Struktur halaman web berbasis **Semantic HTML** (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- Halaman web dengan tampilan visual dan *layout* rapi menggunakan CSS (Tailwind CSS & custom design tokens).
- Desain antarmuka yang responsif di berbagai perangkat (desktop & mobile) tanpa *horizontal overflow* (`overflow-x-clip`).
- Belum mencakup interaktivitas state JavaScript (Pertemuan 3) maupun integrasi REST API / Backend (Pertemuan 4).

## Cara Menjalankan
```bash
cd frontend
npm install
npm run dev
```
