# Week 2 — Sprint 01: Build the DR. MEOWW Web Interface (HTML & CSS)

## Target Pertemuan 2
- Struktur halaman web berbasis **Semantic HTML5** murni (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<details>`, `<footer>`).
- Styling modular menggunakan **CSS Murni** (`frontend/css/`):
  - `tokens.css` — Reset & CSS Custom Properties (design tokens).
  - `components.css` — Tombol, badge, tab pill, dan header seksi.
  - `navbar-hero.css` — Navigasi responsif, Hero, dan seksi Keunggulan.
  - `pricing-delivery.css` — Katalog harga dan metode layanan.
  - `showcase-branch.css` — Komparasi Before-After dan lokasi cabang.
  - `faq-footer.css` — FAQ, banner CTA, dan footer.
- Desain responsif desktop & mobile tanpa *horizontal overflow* dan **tanpa JavaScript (`0% JS`)**.

## Cara Membuka
Buka langsung file `frontend/index.html` di browser atau jalankan melalui *Live Server*.
